# Breathe privacy policy

Public privacy policy for **Breathe / Breath Meditation**, developed by **arkn**.

Published page: <https://arkn-tol.github.io/breathe-privacy-policy/>

Privacy contact: <fgb3420@gmail.com>

This repository contains only the static policy page. It has no contact form,
scripts, database, app source, or signing material.

## Publishing

GitHub Pages publishes `index.html` from the root of the `codex/privacy-policy`
branch. `.nojekyll` disables Jekyll processing. Changes pushed to that branch
update the public page after GitHub's Pages deployment completes.
